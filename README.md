# Digi Ultimate King of the Hill Overlay

OBS-ready static overlay for the three KOTH stages:
- Paid Subs + Gifters
- Non-Sub KOTH
- Final Battle

The overlay is transparent around the leaderboard so it can be used as an OBS Browser Source.

## Current state
This first hosted version reads KOTH data from browser localStorage. A remote live-sync control panel requires a small shared backend; that will be added separately so a mod can update the overlay from another device without exposing a secret token in the public page.
